1. What already exists

  • The Elijah release branch contains shared gym models, tenant configuration, branding, session restoration, switching, gym administration screens and consumer features.
  • YMCA Yonkers and KMF have bundled identities and images in the shared gym model. They are not separate app codebases.
  • The mobile branch includes tenant membership, selection, branding and server authorization code. Its bootstrap checks membership and licensing before returning context.
  • The previous subscription changes are already on the remote Elijah branch: both signup roles can activate purchases, four store products share a catalog, receipt compatibility was improved, and consumer listeners ignore gym purchases.

Evidence limitation: these are source observations. A visible screen or a bundled gym record is not proof of an active production tenant or a working booking journey.
